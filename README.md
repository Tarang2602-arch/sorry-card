# I'm Sorry 🥺 — a cute interactive card

Open the envelope, read the letter, flip the promise cards, and answer the big question (the "No" button runs away 😜).

**Live:** https://tarang2602-arch.github.io/sorry-card/

## Personalize it
Add names (and an optional message) to the link:

```
https://tarang2602-arch.github.io/sorry-card/?to=Riya&from=Tarang
https://tarang2602-arch.github.io/sorry-card/?to=Riya&from=Tarang&msg=Your%20own%20message%20here
```

Built with plain HTML/CSS/JS, Google Fonts (Fredoka, Caveat, Nunito), an inline SVG bear, canvas confetti and a Web Audio tune.
